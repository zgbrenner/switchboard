# Security policy

Please report suspected vulnerabilities through GitHub private vulnerability reporting rather than a public issue.

High-priority areas include archive parsing, file-type confusion, prompt or file-content persistence, unexpected network requests, remote-code execution, overly broad extension permissions, and provider-adapter behavior that submits a prompt without the user's initiating action.

Switchboard's intended security boundary is documented in [docs/privacy.md](docs/privacy.md).
